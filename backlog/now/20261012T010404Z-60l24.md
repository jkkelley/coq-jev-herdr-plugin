# The architect is woken by herdr, not by its own watchers: bringup places an idle watch that prompts the architect pane when a seat goes idle or done, and recover.sh checks podman and runs podman system migrate when the pause process is gone

<!-- item

added: 2026-10-12T01:04:04Z
-->

- why: On 2026-10-12 after the herdr restart, five re-seated seats sat green (idle) in herdr for up to ten minutes while the architect waited, because the only thing that woke the architect was a file watcher it arms by hand in its own session, and that watcher died with the session. The owner could see the idle seats; the system could not tell its architect. The same restart killed podman's rootless pause process, which broke every lint and test run until a seat reported it.
- done-when: herdr/bin/bringup.sh --check lists an idle-watch pane and fails when it is gone; killing the architect's session and resuming it, a seat that turns idle produces one herdr agent prompt into the architect pane within 30 s with the seat name and its last record id; recover.sh --check prints FAILED podman when podman ps errors, and --apply runs podman system migrate and prints fixed podman
