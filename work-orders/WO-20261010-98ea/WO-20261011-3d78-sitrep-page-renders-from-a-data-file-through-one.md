## Problem

The owner locked the SITREP shape on 2026-10-11 (SITREP 003, iteration 2): header strip, phase strip, ticket board with 4-char id chips and a folded legend of full titles, fault, spike, held and one question block. Today it is a hand-written HTML artifact, so the next SITREP drifts. DEC-templates-over-handwriting says records are generated by scripts from templates.

## Scope

**In**

- report/sitrep/sitrep.sh render <entry.json> [--out FILE] fills report/sitrep/assets/template.html from a JSON entry validated against report/sitrep/schema/sitrep.schema.json; render refuses an entry that fails the schema or names a ticket id with no legend title
- entries live under report/sitrep/entries/YYYY/MM/YYYYMMDD-sitrep-NNN.json; the 003 entry is the first and renders byte-identical in structure to the locked artifact
- a Podman case renders the 003 entry and asserts the sections, the id chips and the legend; make lint stays green

**Out - non-goals**

- publishing: the rendered file is handed to the Artifact tool or bearings by the seat that reports
- the rail page under report/rail
